# Building the research paper

From the repository root, run the following command with Tectonic installed.

```sh
tectonic --outdir docs paper/droidfork.tex
```

The two included figures under `docs/` are matching crops of the winning child's recorded full-resolution Android frames. The PDF uses relative paths so the same command works in the downloadable source bundle. [Published PDF](https://nikitph.github.io/droidfork/droidfork.pdf)
